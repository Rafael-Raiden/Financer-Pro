⬇️ Exportar Dados Atuais
💡 Como funciona
1️⃣ Exporte o CSV no app do seu banco (extrato)
2️⃣ Arraste o arquivo na área acima
3️⃣ Mapeie as colunas (data, descrição, valor)
4️⃣ Revise o preview e clique em Importar
Dica Nubank: App → Extrato → Exportar CSV
Dica Itaú/BB: Internet Banking → Extrato → Baixar OFX
Dica Inter: App → Extrato → Exportar → CSV
⚙️ Configurações Gerais
Protege sua planilha: sem o token, quem descobrir a URL não consegue ler nem alterar os dados.
📝 Guia de Instalação

Para conectar ao Google Sheets:

  1. Acesse script.google.com
  2. Crie um novo projeto
  3. Cole o conteúdo do arquivo AppsScript.js
  4. Salve (Ctrl+S)
  5. Execute inicializarPlanilha()
  6. Vá em Implantar → Nova implantação
  7. Tipo: Aplicativo da Web
  8. Quem pode acessar: Qualquer pessoa
  9. Copie a URL gerada e cole nas configurações
💾 Cache Local

Os dados são salvos automaticamente no seu dispositivo após cada sincronização. Mesmo sem conexão com a planilha, o app exibe os últimos valores carregados.
